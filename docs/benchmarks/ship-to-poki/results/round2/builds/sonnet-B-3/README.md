# Skyhop

Hop between floating islands, collect gems, and dodge storm clouds. Arrow keys or WASD move, space jumps. On touch screens, tap the left or right third of the screen to move and the middle third to jump.

Submitting to Poki. The Poki SDK is wrapped in `src/sdk.js`; check it with `node .claude/skills/web-portal-preflight/scripts/preflight.mjs --config preflight.config.json`, then with the Poki Inspector.
