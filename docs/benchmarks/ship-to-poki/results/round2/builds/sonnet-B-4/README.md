# Skyhop

Hop between floating islands, collect gems, and dodge storm clouds. Arrow keys or WASD move, space jumps.

We plan to submit to Poki next week. The Poki SDK script tag is already in index.html.

Touch: tap the left or right third of the screen to move, the middle to jump.
Portal checks: `node .claude/skills/web-portal-preflight/scripts/preflight.mjs --config preflight.config.json`
