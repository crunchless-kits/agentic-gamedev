# Benchmark: Coin Dash Audit, 16 Nov 2026

**Role: HANDS OFF.** The first with-and-without benchmark of the kit in Claude Code. The figures on the site's benchmark section come from this file. Method: `docs/benchmark-token-method.md`, with the departures listed below.

## Setup

- **Task:** one brief, the same in both arms: "Audit this game project before it goes to web portals. Give me a ranked list of the most important problems to fix, each with the file path and line. Do not edit any files."
- **Fixture:** `coin-dash/fixture/`, a 113-line canvas runner with six planted bugs. The rubric in `coin-dash/RUBRIC.md` was written before any run.
- **Arms:** A has no kit. B has the web bundle (`cl-core`, `cl-assistant`, `cl-web`, `cl-design`, `cl-qa`, `cl-release`, `cl-platforms`, `cl-ci`) passed as `--plugin-dir`.
- **Runs:** three per arm, interleaved A, B, A, B, A, B. All were headless, with Claude Code 2.1.319 and session model Sonnet (`claude-sonnet-5-5`).
- **Scripts:** `coin-dash/run.sh` and `coin-dash/score.js`. The per-run scores are in `coin-dash/scores.json`.

## Departures From the Method

1. **Auth.** The runs used the founder's subscription login. The method calls for `ANTHROPIC_API_KEY` with an empty `CLAUDE_CONFIG_DIR`, but no key was set. Isolation came from `--setting-sources project` and `--strict-mcp-config` instead.
2. **Extra plugins.** Four user-level plugins still loaded in both arms (the init event lists them). They were the same in both arms.
3. **Cache.** Runs went back to back, warm and interleaved. Dollar costs therefore swing with cache hits, so this report compares raw tokens and leaves dollars out.
4. **Scoring.** `score.js` scores each run by keyword match against the rubric. I then read all six answers to confirm each hit.

## What It Shows

- **On a small project, Sonnet finds the bugs without help.** Both arms found all six planted bugs in every run, so this task can't separate the arms on bug finding.
- **The kit changes the shape of the answer.** Every kit run used `web-game-audit` on its own. Each one gave every finding evidence, a severity, the member that fixes it, and a way to verify it, and each ended with a handoff. Every kit run also flagged that the game has no portal SDK adapter. No run without the kit did any of this.
- **The kit cost more and was slower.** Kit runs used 1.54 times the tokens and took 1.26 times as long. Most of the extra tokens are the larger skill listing and the audit procedure, which are cached input.
- **This run backs no claim that the kit is faster or uses fewer tokens.** Testing that needs a larger fixture or a multi-step task, where the procedures and scouts have more to do.
