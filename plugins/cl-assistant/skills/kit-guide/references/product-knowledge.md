## Commands

- /cl-audit (free): Audit this game project with parallel scouts and route ranked findings to specialists. Use on an existing or unfamiliar game project.
- /cl-doctor (free): Check the first-run environment: Node, Claude Code, hooks, kit version, description load, engine. Use after install or when the kit misbehaves.
- /cl-help (free): Say what the kit can do for a goal, engine, platform, or service, and the next command. Use when unsure which member fits or what is installed.
- /cl-learn (builder): Teach the kit your brand, voice, code style, review habits, and lessons in .cl/house/. Use when output doesn't sound, look, or code like your studio.
- /cl-plan (free): Turn a task into a phased plan with checks per phase and a Not Doing list, then refine it or build it one phase at a time. Use before a change that spans files or sessions.
- /cl-port (builder): Port the game to a web portal or ad network through a game-owned adapter. Use for Poki, CrazyGames, GameDistribution, YouTube Playables, and others.
- /cl-review (builder): Adversarial review of the current change: correctness, feasibility against spec, and pacing. Use before a merge or when work runs long.
- /cl-ship (free): One documented ship or no-ship decision from gate evidence gathered in parallel. Use before any release or store or portal submission.
- /cl-start (free): First-hour onboarding: detect engine and stage, recommend plugins, run the audit script, name next commands. Use when new to the kit or a project.
- /cl-suggest (free): Suggest a change to the kit itself: a missing skill, a wrong step, or a rule it should know. Logs it and, on your yes, files it on GitHub for the next update.
- /cl-ask (free): Ask the Crunchless guide about the kit: install, tiers, which member fits, troubleshooting. Use for any question about Crunchless itself.
- /cl-brainstorm (free): Constraint-first brainstorm returning ranked, mechanically distinct options. Use for a new game idea, a jam, or a stalled prototype.
- /cl-gdd (builder): Author or retrofit one system's design doc with named numbers and cross-references. Use when a system needs a buildable spec.
- /cl-producer (studio): Studio producer: status, what's next, the week, tickets, agent usage, expenses, prototype scoping. Use for planning across your games.
- /cl-market (studio): Turn this week's work into a post plan and drafts in your house voice. Drafts only. Use when it is time to plan the week's posts.
