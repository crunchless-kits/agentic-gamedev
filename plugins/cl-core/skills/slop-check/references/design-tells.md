# Design tells and what to do instead

Twenty tells seen in AI-generated interfaces and pages, plus five more that travel with them. Each is a default, not a crime; keep one only when the style guide says why.

| # | Tell | Why it reads as generated | Instead |
| --- | --- | --- | --- |
| 1 | Tags and pills | Labels as decoration, no information | Plain text labels; a pill only for a real status or filter |
| 2 | Excessive italics | Italics for rhythm | Italics for titles and emphasis once per screen |
| 3 | Instrument Serif and its cousins as display type | The default "tasteful" serif | Pick type from the subject; a serif needs a reason |
| 4 | Negative kerning on headings | Tightened display type as a reflex | Default tracking; tighten only above 64 px and only if the typeface needs it |
| 5 | Over-the-top detailed UI | Density as a proxy for quality | Show the three things the user needs; hide the rest behind a tap |
| 6 | Overusing dividers | Rules between every row and section | Space and tone changes separate sections; a rule only where two adjacent blocks would merge |
| 7 | Color shades and opacities | Translucent whites and blacks instead of a palette | A named palette with roles; opacity only for real layering (overlays, disabled) |
| 8 | Containers with borders | Every card outlined | Background tone, spacing, or nothing; a border only for inputs and selected states |
| 9 | Overly detailed diagrams | More nodes than ideas | One idea per diagram, under eight nodes, labeled edges |
| 10 | Verbose, redundant text | Three sentences saying one thing | One sentence per idea; cut the restatement |
| 11 | Code breadcrumbs | `home / product / feature` as decoration | Real navigation or nothing |
| 12 | Section numbering | 01, 02, 03 on marketing sections | Numbers only for ordered procedures |
| 13 | Eyebrows | Small uppercase label above every heading | Let the heading do the work; a kicker only when the category changes |
| 14 | Dithering | Retro texture by default | Only in a deliberate pixel or retro art direction |
| 15 | ASCII images | Box-drawing art and ASCII logos | A real image, an SVG, or no image |
| 16 | Squircles | Large radii everywhere | A radius scale with two values; large radii only on the largest surfaces |
| 17 | Excessive mono fonts | Mono for labels, numbers, and headings | Mono for code and identifiers only |
| 18 | All-caps subtitles | Shouted secondary text | Sentence case with size and weight for hierarchy |
| 19 | Gradient backgrounds | Glows, meshes, and fades | Flat color; one accent; texture from content |
| 20 | Periods in titles | Headlines ending with a full stop | No terminal punctuation in headings |
| 21 | Three equal cards with icons | The default section shape | Vary section shape by content; one column when the content is one thing |
| 22 | Everything centered | Centered hero, centered cards, centered everything | Left-aligned text above 40 characters; center only short lines |
| 23 | Glassmorphism and blur panels | Frosted overlays as a style | Solid surfaces |
| 24 | Stock hero metrics | "10x faster", "99.9%" without a source | Real numbers with a source, or none |
| 25 | Icon soup | A decorative icon per bullet | Icons only when they carry meaning across the product |

## Game UI specifics

- HUD and menus follow the game's style guide; the tells above still apply to menus, store screens, and settings.
- Pixel art, dithering, CRT, and mono type are legitimate art directions when the style guide says so; the guard is intent, not taste.
- A results screen that lists eight stats in pills with dividers between them is the in-game version of tells 1, 6, and 10.
