# House rules (writing and chat)

Taste, not law. Delete what the studio does not want; every skill reads this file.

## Prose
- No em dashes. Use a colon, a comma, or a new sentence.
- Oxford comma on lists of three or more.
- One spelling convention (American by default).
- Pick one heading style and keep it: sentence case (the kit's default) or Title Case.
- Avoid "X, not Y" phrasing, "X, verbed" headlines, and lists of three used for rhythm.
- Plain words; a number beats an adjective; no filler openers.
- Optional: no runts (a last line of one or two words) in UI and printed copy.
- State confidence honestly: [seen], [sourced], [starting value], "judgment", "estimated".

## Collaborator-facing text
- Never label text as AI, draft, or generated; write "needs review" when it does.
- Chat markdown: `- ` bullets, two spaces per nesting level, headings only for major callouts.
- Each to-do starts with a verb and names its deadline or file.

## Claims
- Every claim about a game is true in the build the reader can open.
