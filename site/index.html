Install It, Then Run the Audit

Install the core and your engine’s plugin, then run the audit in your game’s folder. You get a ranked list of what to fix, with file paths. The rest of the kit works the same way, from the first idea to the store page.

What Comes Back

One finding and the closing handoff from a kit audit of the benchmark game, copied as the agent wrote them.

3. [blocker] No `gameplayStart`, `gameplayStop` or `gameLoadingFinished` calls.
   Evidence: `src/sdk.js:1-8` only exposes `init` and `commercialBreak`. A grep of `src/` finds no other Poki calls.
   Impact: Poki requires these events, and QA will reject a build without them. They also drive ad timing and Poki's metrics.
   Fix: Call `gameLoadingFinished` after boot. Call `gameplayStart` at run start and `gameplayStop` at game over, and again around ads.
   Route to: `cl-core:cl-port`.

## Handoff
Changed: nothing (audit only).
Evidence: I read all 11 tracked files (`README.md`, `package.json`, `index.html`, `style.css`, `assets/manifest.json` and `src/*.js`).
Verify: To reproduce finding 2, block `poki-sdk.js` in DevTools and reload. The canvas stays blank and the console shows a `PokiSDK is not defined` error. For finding 5, die and restart three times, then die and press Space once. Several ads fire.
Open:
- I did not run the game in a browser, so there are no measured frame rates or load times.
- I did not check `assets/` on disk. The sizes come from `manifest.json`, and the actual audio files are not in the repo.
- I could not confirm Poki's current size limit or review rules. The requirements above come from my knowledge of Poki's guidelines, so check them against the current Poki developer docs.
Next: Fix the four blockers, which are the audio size, SDK init failure, the Poki lifecycle events and the leaderboard fetch. Then do finding 5 (stacked listeners), because it breaks ad pacing.

Straight Answers

Does it write my game for me?

Your coding agent writes the code. Crunchless gives it the procedures, the audits, the guardrails, and the shipping steps, and checks the work with file paths.

Which coding agents does it support?

Claude Code installs the kit as plugins. For Codex, GitHub Copilot, Cursor, and Antigravity, an export script writes it into your agent’s own folders. All four loaded the kit and ran its scripts in a seven-check test in November 2026.

Do I have to use generated art or audio?

Never. The asset skills point to CC0 and CC-BY libraries and record where each asset came from. Generative art and audio services connect only if you choose one.

What happens when an SDK changes?

Every platform note carries a verified date. A scheduled monthly job re-reads the sources and opens an update for review, and anything older than 90 days is re-verified before code is written.

What do I need?

A coding agent, Node.js 22 or newer, Git, and your engine installed for anything that builds or runs.

Where do I get help?

GitHub Discussions, answered within three business days. Every version is tagged with release notes.
