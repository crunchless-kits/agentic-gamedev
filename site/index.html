Straight Answers

Does it write my game for me?

Your coding agent writes the code. The kit shows it how, and checks the work.

Which coding agents does it support?

Claude Code, as plugins. Codex, GitHub Copilot, Cursor, and Antigravity, through an export script.

Do I have to use generated art or audio?

Never. The kit points to free asset libraries, and generative services connect only if you choose one.

What happens when an SDK changes?

Every platform note is dated. Notes older than 90 days are checked against the live docs before any code is written.

What do I need?

A coding agent, Node.js 22 or newer, Git, and your engine installed for anything that builds or runs.

Where do I get help?

GitHub Discussions, answered within three business days.
